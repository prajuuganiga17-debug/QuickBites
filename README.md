# 🍜 QuickBite: Street Food Delivery Web App

Welcome to **QuickBite**, a premium, street-food-themed food delivery website built entirely from scratch! This project demonstrates a deep understanding of modern web design principles using only core web technologies. 🚀

## 🌟 Project Overview

QuickBite is designed to rival real-world applications like Swiggy or Zomato but with a unique, bold "Street Food" aesthetic. The design features a "butcher paper" background, neon red accents, and high-quality imagery to create a mouth-watering user experience. 🤤

This project serves as a comprehensive showcase of **Advanced CSS concepts** and **Semantic HTML5** structuring. No external CSS frameworks (like Bootstrap or Tailwind) or JavaScript were used for the layout and styling, ensuring a pure, fundamental approach to web development. 🛠️

## ✨ Key Features & Design Aesthetic

*   **🎨 "Street Food" Theme:** A curated colour palette featuring deep espresso (`#1A0F05`), warm stone (`#7A6A54`), neon red (`#F23C3C`), and butcher paper neutral (`#F5E9CF`).
*   **📱 Fully Responsive:** The layout seamlessly adapts to mobile, tablet, and desktop screens using CSS Media Queries and flexible Grid/Flexbox layouts.
*   **🖼️ Rich Imagery:** High-quality, AI-generated premium food photography that makes the application visually stunning and appetizing.
*   **✨ Glassmorphism & Depth:** Strategic use of `box-shadow`, `backdrop-filter`, and gradients to create a modern, layered interface.
*   **🖱️ Dynamic Interactions:** Engaging micro-animations and hover effects on buttons, cards, and navigation links to bring the site to life.
*   **🔤 Premium Typography:** Utilizes Google Fonts "Bowlby One" for impactful display headings and "DM Sans" for clean, readable body text.

## 🧠 Technical Highlights (What's Inside)

This project heavily focuses on mastering CSS. Here is a breakdown of the CSS properties and concepts implemented:

### 📦 The Box Model Mastery
*   Extensive use of `margin`, `padding`, and `border` to control spacing and layout precisely.
*   Implementation of `box-sizing: border-box` globally for predictable sizing.
*   Creative application of `border-radius` to soften edges and create modern UI elements like pills and rounded cards.

### ✍️ Typography & Text Styling
*   **Text Transformation:** `text-transform` (uppercase, capitalize) for badges, labels, and headings.
*   **Text Spacing:** Fine-tuned `letter-spacing` and `word-spacing` for optimal readability and aesthetic appeal.
*   **Text Decoration:** Controlled `text-decoration` for links and interactive elements.
*   **Text Shadow:** Multi-layered `text-shadow` to give depth and "glow" to important text.
*   **Line Height & White Space:** Managed `line-height` for paragraphs and `white-space` control for tags and badges.

### 🎨 Colors & Backgrounds
*   Implementation of CSS Custom Properties (Variables) for a consistent and easily maintainable color system.
*   Complex background setups including linear and radial gradients.
*   Use of `color` and background-color properties to maintain high contrast and readability.

### 📐 Layout & Positioning
*   **Flexbox & Grid:** Robust use of CSS `display: flex` and `display: grid` to structure complex layouts like the hero section, food cards, and footer.
*   **Positioning:** Strategic use of `position: relative`, `absolute`, and `sticky` (for the navigation bar).

### 🚀 Selectors & Advanced CSS
*   Comprehensive use of standard selectors (ID, Class, Element).
*   Application of Combinators (Descendant, Child).
*   Rich use of Pseudo-classes (`:hover`, `:focus`, `:active`, `:nth-child`) and Pseudo-elements (`::before`, `::after`, `::selection`, `::placeholder`) for styling and decorative elements without adding extra HTML markup.
*   Smooth `transition` and keyframe `animation` implementations.

## 📂 File Structure

*   `index.html`: The core semantic HTML structure of the application.
*   `style.css`: The comprehensive stylesheet containing all design logic and tokens.
*   `*.png`: High-quality, generated food and restaurant assets used throughout the site.

## 🚀 How to Run

1.  Clone or download this repository.
2.  Navigate to the project folder.
3.  Open the `index.html` file in any modern web browser. That's it! No build steps required. 🎉
